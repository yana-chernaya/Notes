# Notes
**Notes** is an Android app for creating and storing notes. Notes can contain text and images in any order, and support searching and pinning to the top of the list.

## Key Features
* Create, edit, and delete notes
* Pin important notes to the top of the list
* Mix content — use text and images in a single note in any order
* Search through notes
* Save images from notes to the app’s internal storage.

## Tech Stack
| Category | Library / Tool |
|:----------|:-----------|

| Navigation | Navigation Compose |
