# Notes
**Notes** — Android-приложение для создания и хранения заметок. Заметки могут содержать текст и изображения в произвольном порядке, поддерживают поиск и закрепление наверху списка.

## Основные возможности приложения
* Создание, редактирование и удаление заметок.
* Закрепление важных заметок наверху списка.
* Смешанный контент — текст и изображения в одной заметке в любом порядке.
* Поиск по заметкам.
* Сохранение изображений заметок во внутреннем хранилище приложения.
